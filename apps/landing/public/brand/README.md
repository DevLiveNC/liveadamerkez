# Marka varlıkları

Logo A wordmark **kesin**. Kaynak: `logo-v3/final/`.

| Dosya | Kullanım |
|---|---|
| `logo.svg` | Wordmark, açık zemin. `Logo` bileşeni. |
| `logo-koyu.svg` | Wordmark, koyu zemin. |
| `icon.svg` | Mercan kare A (PWA / favicon kaynağı). |
| `icon-maskable.svg` | Maskable (güvenli alan ortada). |

PWA PNG’leri `public/icons/` ve `public/favicon-*.png` altındadır.
